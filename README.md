# 欢迎使用 NapcatQUI！

## 这个项目是怎么回事？

起因是我重装了系统，我不想让 QQ 污染我崭新的系统，折腾别的非官方客户端要么风控要么麻烦反正就是搞不定。

转念一想，想到自己的 bot 活的好好的，为什么不用同一个方案呢？

我试着搜索了一下现有的项目，但似乎没有前人想到这个逆天玩意（或者纯我没发现）。

于是，这个基于 Napcat 的 QUI 就诞生了。

## 警告

- 这个项目还很草率，请不要过于相信此项目，包括但不限于没考虑安全性、代码质量低（全 ai 开发）、美术质量差（全是 emoji）。
- 此项目不对任何安全问题做担保

## 如何使用

1. 部署一个 Napcat。
2. 启动 ws 服务器
3. 把相关信息填进 NapcatQUI
4. 完成

## 已经实现的功能

- 最基础的聊天功能
- 戳人、at、引用
- gif 播放
- 内置看图（虽然但是这个真的该留着吗）

## 已经发现的问题

- 图片发不出去
- 没法撤回消息
- 丢消息太严重
- 其他
