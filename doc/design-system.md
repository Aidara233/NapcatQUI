# NapcatQUI 设计系统

> 视觉方向：**暖灰午后 (Warm Gray Afternoon)** — 一只在午后阳光里打盹的猫，安静、温暖、不费力气

---

## 一、设计决策

### 1.1 为什么是这个方向

QQ 的蓝色已经用了二十年，WeChat 的绿色也刻进了所有人的视网膜，Discord 的灰紫色、Telegram 的亮蓝、Slack 的彩色条——每个聊天软件都在颜色上选了阵营。NapcatQUI 不需要争这个。它不是另一个 IM，它是一个人为了逃离 QQ 而给自己做的工具。

"Napcat" 这个名字是一种情绪：猫在打盹，安静，不被打扰。聊天软件不应该是焦虑来源。所以整个视觉应该传递的是**安静**和**温暖**，而不是"看这里！看这里！"的通知焦虑。

暖灰做底，琥珀做点缀——没有哪个主流聊天软件用过这个配色。它不会让人想起任何竞品，也不会让人想起 QQ。

### 1.2 唯一的设计风险

自发送消息的气泡带有极微弱的暖色渐变——几乎看不出来，但在白色消息气泡群里，只有你发的那条是"暖"的。这可能会让某些用户觉得奇怪（为什么只有我的气泡不一样），但它也在潜意识里区分了"我"和"别人"。这个风险值得冒。

### 1.3 有意避免的东西

- 蓝色——"这是另一个 QQ"
- 纯黑背景暗色模式——"这是 Discord/Slack"
- 大圆角、阴影、卡片——"这是 Material Design 模板"
- 超过两种字体——桌面应用不需要字体表演
- 动画过多——聊天软件不是展示类网站

### 2.3 消息气泡色

| 类型 | 浅色 | 暗色 |
|------|------|------|
| 对方消息气泡 | `#FFFFFF` (border: `#E5E2DD`) | `#282725` (border: `#383632`) |
| 自己消息气泡 | `accent-muted` (`#F5EDE3` → `#F0E5D6` 微弱渐变顶到底) | `accent-muted` (`#3A3026` → `#352C22`) |

## 三、字体

### 3.1 选型

桌面 QQ 客户端的中文字体只有一条靠谱的路：**思源黑体 (Source Han Sans SC)**。Windows 上微软雅黑是系统默认但它太"方"，macOS 上苹方很好但跨平台不一致。思源黑体开源免费，可以随应用打包，保证三端视觉统一。

| 用途 | 字体 | 备选 |
|------|------|------|
| UI 正文（中文） | Source Han Sans SC (Regular/Medium/Bold) | 微软雅黑 → 苹方 → 系统默认 sans-serif |
| 代码/时间戳 | JetBrains Mono (可选打包) | Consolas → 系统默认 monospace |

不引入第二套中文字体。聊天软件不是杂志，字体变化少是一种克制。

### 3.2 字号阶梯

Avalonia 没有 CSS 的 `rem`，但可以定义一个基准尺寸常量。以下以 Windows 96 DPI 为基准：

| 层级 | 字号 | 行高 | 用途 |
|------|------|------|------|
| `text-xs` | 11px | 16px | 时间戳、系统消息、辅助标签 |
| `text-sm` | 13px | 18px | 消息预览、联系人状态、群名片 |
| `text-base` | 14px | 20px | 联系人名称、消息正文、按钮文字 |
| `text-lg` | 16px | 24px | 会话标题、设置标题 |
| `text-xl` | 20px | 28px | 面板标题（极少用） |

**字号不做"体验缩放"**——不要给用户一个"字体大小"滑块。14px 中文 UI 是最佳平衡点，QQ 自己的消息正文也是 14px。

### 3.3 字重使用

- Regular (400)：联系人列表、消息正文、输入框 — 绝大多数文字
- Medium (500)：联系人名称、会话标题 — 需要稍微突出但不至于"这是标题"的地方
- Bold (700)：未读计数、强调标签、设置页标题 — 极少使用

字重是用来建立信息层级的，不是用来装饰的。能用 Regular 的地方不用 Medium，能用 Medium 的地方不用 Bold。

## 五、组件设计

### 5.1 聊天气泡

```
对方消息 ──┐
           │   ┌──────────────────────────┐
           │   │ 对方的昵称 (13px, Medium)  │  ← 群聊才显示，私聊隐藏
           │   │ 消息正文 (14px, Regular)   │
           │   └──────────────────────────┘
           │   时间 12:34 (11px, tertiary)    ← 每条最后一条显示，同组隐藏

自己消息 ──┐
           │                        12:34 ✓✓
           │   ┌──────────────────────────┐
           │   │ 消息正文 (14px, Regular)   │
           │   └──────────────────────────┘
           └──────────────────────────────  ← 右对齐
```

**气泡细节**：
- 圆角：10px（比 WeChat 的 4px 略圆，比 Telegram 的 12px-18px 略方）
- 对方气泡：白底 (`bg-surface`) + `border` 色 1px 描边
- 自己气泡：`accent-muted` 底，无描边
- 气泡最大宽度：聊天区宽度的 65%（约 400-500px），长消息自动换行
- 气泡内边距：上下 8px，左右 12px
- 气泡尾部小三角：3px 高的微三角，自己消息右侧、对方消息左侧（纯装饰，去掉也可以——先做上去看效果，如果显得"太像 QQ 山寨"就砍掉）
- 图片消息：圆角 8px，最大宽 320px，点击放大

### 5.2 联系人列表

```
┌────────────────────────────────────┐
│ 🔍 搜索 (28px, 顶部固定)            │
├────────────────────────────────────┤
│ ▼ 好友                    (折叠分组) │
│ ┌────────────────────────────────┐ │
│ │ [头像40px] 联系人名称           │ │  ← hover: bg-hover
│ │             最后一条消息预览...  │ │  ← 最多一行，超出省略
│ │                               │ │
│ │ [头像]     另一个联系人         │ │  ← active: bg-active, 左侧2px accent色条
│ │             [2条未读]          │ │
│ └────────────────────────────────┘ │
│ ▼ 群聊                             │
│ ┌────────────────────────────────┐ │
│ │ [群头像]   群名称               │ │
│ │            某某: 最后一条消息..  │ │  ← 群聊显示发送者昵称
│ └────────────────────────────────┘ │
└────────────────────────────────────┘
```

**关键细节**：
- 未读气泡：`accent` 色 18×16px 小胶囊，数字白色，没有未读时不显示
- 选中指示：2px 宽的 `accent` 色竖条在列表项左侧，不是整行变色
- 群头像：4 宫格拼接（取前 4 个群成员头像），这个细节很 QQ，值得保留
- 置顶会话：浅 `accent-muted` 背景，图钉图标
- 免打扰会话：名称右侧小铃铛斜线图标

### 5.3 输入区域

```
┌─────────────────────────────────────────┐
│ [工具栏 32px]                             │
│  😊  📎  🖼️  📁  ✂️  ...             │  ← 图标按钮，间距 4px
├─────────────────────────────────────────┤

- Ctrl+Enter 发送，Enter 换行（像 QQ，可配置互换）

## 六、动效

### 6.1 原则

桌面应用不是网页。Avalonia 的动画能力有限，而且大多数"酷炫"的转场动画在聊天软件里是减分项——消息列表是最频繁交互的区域，动画延迟哪怕 200ms 也会让人觉得"卡"。

允许的动效：
- 消息出现：无动画，直接渲染。消息应该"瞬发"，不应该滑进来或淡入
- 联系人列表切换：左侧选中指示条 150ms 缓动位移（不是整行变色）
- 抽屉滑入：280px 从右滑入，200ms ease-out
- 发送按钮：hover 时背景色 150ms 过渡，active 时缩放 97%
- 未读标记：数字变化时无动画，出现/消失时 150ms scale 弹性
- 窗口最小化到托盘：无动画

不做的动效：
- 消息气泡淡入/弹入
- 联系人列表虚拟滚动的"骨架屏"
- 页面转场
- 头像加载 shimmer

### 6.2 微交互

- 右键菜单：原生系统上下文菜单（不是自定义），保持平台一致性
- 图片 hover：轻微放大镜光标 + 1px `accent` 边框出现
- 可点击元素 hover：150ms `bg-hover` 过渡
- 按钮 active：97% scale，给人"按下去了"的反馈
- 滚动条：3px 宽，`border-strong` 色，hover 时变 `text-tertiary`。**不用系统默认滚动条**

## 七、图标

### 7.1 来源

图标有两个选择：
1. **Phosphor Icons**（开源，MIT 协议，6000+ 图标，风格统一）— 推荐
2. 自己画（没必要，聊天软件的功能图标没有差异化价值）

### 7.2 颜色

- 导航栏图标：当前激活页 `accent`，其他 `text-tertiary`，hover `text-secondary`
- 工具栏图标：`text-secondary`，hover `text-primary`
- 操作图标（标题栏）：`text-secondary`，危险操作用 `danger`

## 八、空状态

这是整个应用最该花心思的"静止画面"。

```
┌──────────────────────────────────┐
│                                  │
│                                  │
│            🐱                    │  ← 一只小睡猫的极简线条画
│                                  │     (SVG, 64px, text-tertiary 色)

### 8.2 无搜索结果

```
  没有找到 "xxx" 相关的结果
```

不道歉，不说"抱歉"。就说事实。11px，居中。

### 8.3 无消息历史

```
  还没有消息，打个招呼吧
```

只在第一次打开一个会话时出现，加载完历史消息后自动消失。

## 九、主题切换

- 支持浅色/暗色/跟随系统，默认跟随系统
- 主题切换时无动画，直接切换（Avalonia 的 `ThemeVariant` 机制）
- 所有颜色都从 Token 引用，不写死色值——改 Token 即改全局
- 不做"自定义主题色"功能（这是聊天工具，不是设计工具）

## 十、实现备忘（Avalonia 特有关注点）

- 用 `ResourceDictionary` 定义所有颜色 Token，XAML 中通过 `{DynamicResource}` 引用
- 自定义 `ScrollBar` 样式写在 `Styles.xaml` 里，全局生效
- 联系人列表用 `VirtualizingStackPanel` + `RecycleItems`，别用 `ListBox` 的默认面板
- 聊天气泡用 `ItemsControl` + `DataTemplateSelector`（自己消息 vs 对方消息），不要用 `ListBox`
- 输入框的自动增高靠 `TextBox.TextChanged` 事件中手动调整 `Height`（Avalonia 没有 CSS `field-sizing: content`）
- 图片渲染用 `Image` 控件 + 异步加载，缩略图走 SkiaSharp 预处理（避免 UI 线程解码大图）
- 窗口圆角/阴影靠 `Window.TransparencyLevelHint` + 自定义 `WindowDecoration`（Avalonia 11 支持 acrylic 模糊背景）
